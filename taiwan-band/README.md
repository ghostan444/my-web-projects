# 下一團聽什麼？— 完整程式碼

這份程式碼對應目前的網站版本：69 組台灣樂團、六大曲風，沒有語言偏好選項。

## 最快的開啟方式

1. 將 ZIP 完整解壓縮。
2. 用 Chrome 或 Edge 開啟 `standalone.html`，即可直接操作。
3. 單檔版已內含樣式、程式與樂團資料，不需要安裝套件或申請 API 金鑰。

## 想練習修改程式碼

建議用 VS Code 開啟整個資料夾，透過 Live Server 的「Open with Live Server」開啟 `index.html`。
分檔版使用 JavaScript 模組與 fetch 讀取資料，需要透過本機網頁伺服器開啟。

如果電腦已有 Python，也可在本資料夾的終端機執行：

```bash
python -m http.server 8000
```

接著在瀏覽器開啟 http://localhost:8000 。Windows 若 `python` 無法執行，可試 `py -m http.server 8000`。

## 檔案用途

| 檔案 | 用途 |
| --- | --- |
| standalone.html | 可直接開啟的完整單檔版 |
| index.html | 分檔版的頁面結構與 CSS 樣式 |
| app.js | 輸入選項、按鈕、推薦卡片、完整清單與搜尋 |
| recommender.mjs | 曲風選項、團名辨識與推薦分數計算 |
| bands.json | 69 組樂團、曲風、心情、入門歌曲與資料來源 |

單檔版與分檔版各自獨立，修改分檔版不會自動更新單檔版。要持續開發，建議使用分檔版。

## Input / Output

- Input：喜歡的樂團（選填）、偏好的曲風（複選）、今天想聽的感覺、聲音能量。
- 處理：比對曲風、相似樂團標籤、心情與能量，依分數排序。使用喜歡的樂團作為參考時，會排除該團本身。
- Output：最多三組推薦、配對依據、入門歌曲、YouTube 搜尋連結與資料來源。
- 完整清單可用團名、英文名、簡稱與曲風篩選。

六大曲風：獨立搖滾、迷幻搖滾、後搖滾、金屬、龐克、民謠。大象體操歸入獨立搖滾。

## 如何新增樂團

在 bands.json 的陣列中新增一筆物件；id 必須唯一，genres 請使用上述六大曲風。

```json
{
  "id": 69,
  "name": "樂團名稱",
  "en": "Band Name",
  "genres": ["獨立搖滾"],
  "moods": ["放鬆", "浪漫"],
  "energy": 3,
  "song": "入門歌曲名稱",
  "desc": "樂團聲音特色與推薦理由。",
  "source": "https://example.com/",
  "aliases": ["樂團簡稱"]
}
```

energy 為 1 到 5。moods 可使用：放鬆、浪漫、憂鬱、熱血、宣洩、專注。
程式載入後會自動更新樂團數量。JSON 必須使用半形雙引號，最後一筆後面不能加逗號。

## 運作方式與資料

這是用 AI 協助製作的前端作品；推薦採用內建資料與規則配對，不會即時呼叫 AI 或分析音訊。
資料與曲風為探索用的編輯整理，不是官方排名，卡片保留每團的參考來源。
YouTube 按鈕會開啟搜尋結果，並不在網頁內播放音樂。
介面與資料可在本機使用；前往資料來源或 YouTube 時需要網路。

版本日期：2026-10-28。配色：酒紅、暖白底與朱紅點綴。

## 修改配色

單檔版請修改 standalone.html 上方的 `<style>` 區塊；分檔版則修改 index.html 的 `<style>`。CSS 開頭的 `--bg` 是背景色、`--ink` 是主要文字與按鈕色、`--accent` 是重點色、`--line` 是線條色。
